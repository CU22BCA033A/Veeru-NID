# Images needed

Generated by `npm run images:needed`. Do not edit by hand; edit `content/images.json` instead.

**59 photos** are used by **74 questions**. A question stays hidden from tests until all its photos are uploaded.

## How to add a photo

1. Sign in as the mentor and open **Images**.
2. Find the photo by its ID and tap **Upload**. You can take the picture right there with the phone camera.
3. It is compressed automatically and the questions that use it go live.

**Rules:** shoot it yourself, or use only open-licence photos (Wikimedia Commons, Unsplash, Pexels, Pixabay) and record the licence, author and link. Never use Google Images or coaching-site pictures. Don't include people's faces, number plates or brand logos as the main subject.
